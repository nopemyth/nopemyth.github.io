Privacy Policy

App: “Shorts Kanal Uploader” · Operator: NopeMyth (YouTube channel @nopemyth) · Last updated: 6 November 2026

1. Who uses this app

“Shorts Kanal Uploader” is a private internal tool used only by the operator of the YouTube channel NopeMyth (@nopemyth). It is not offered to the public, and no other person signs in to it.

2. Use of YouTube API Services

This app uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service (youtube.com/t/terms). Information is also handled according to the Google Privacy Policy (policies.google.com/privacy).

Through the YouTube Data API v3 the app only:

  • uploads the operator's own videos to the operator's own channel (as private videos, with a scheduled publishing time), sets their thumbnails and adds them to the channel's own playlists,
  • maintains the operator's own channel branding (description, keywords, banner),
  • reads data of the operator's own channel and videos (titles, upload status, view and subscriber counts).

The app does not access, collect or store data of any other user, viewer or channel. It does not read comments, messages, contacts or any personal data of third parties.

3. What is stored, and where

  • OAuth token: stored only on the operator's own server, encrypted with Windows Data Protection (DPAPI). Never shown, logged or shared.
  • Upload log: IDs, titles and upload times of our own videos.
  • Statistics: total view counts of our own channel, used internally to track progress.

No cookies, no tracking and no analytics are used by this app or this website.

4. Sharing

No data is sold, shared with or transferred to third parties. No data is used for advertising.

5. Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access

Access can be revoked at any time via the Google security settings page at security.google.com/settings/security/permissions (also reachable at myaccount.google.com/permissions). After revocation the app can no longer access YouTube; the stored token stops working and the app deletes it automatically on its next run.

7. Data deletion

  • On revocation: the stored token is deleted automatically, and all other stored API data (upload log, statistics) is deleted within 7 days.
  • On request: deletion of stored API data can be requested via the contact below; it is completed within 7 days.
  • Regularly: statistics are only kept as long as needed for internal tracking; stored API data is refreshed or deleted at least every 30 days, except the IDs and titles of our own uploads in the upload log.

8. Contact

Questions or deletion requests: via the YouTube channel NopeMyth (@nopemyth).

Datenschutzerklärung

App: „Shorts Kanal Uploader“ · Betreiber: NopeMyth (YouTube-Kanal @nopemyth) · Stand: 6. November 2026

1. Wer die App nutzt

„Shorts Kanal Uploader“ ist ein privates internes Werkzeug, das ausschließlich der Betreiber des YouTube-Kanals NopeMyth (@nopemyth) nutzt. Die App wird nicht öffentlich angeboten; niemand sonst meldet sich darin an.

2. Nutzung der YouTube-API-Dienste

Diese App nutzt die YouTube-API-Dienste. Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

Über die YouTube Data API v3 macht die App nur Folgendes: eigene Videos auf den eigenen Kanal hochladen (privat, mit geplantem Veröffentlichungszeitpunkt), Thumbnails setzen und Videos eigenen Playlists hinzufügen, das Branding des eigenen Kanals pflegen sowie Daten des eigenen Kanals und der eigenen Videos lesen (Titel, Status, Aufrufe, Abonnenten). Daten anderer Nutzer, Zuschauer oder Kanäle werden weder abgerufen noch gespeichert.

3. Was gespeichert wird

Das OAuth-Token liegt nur auf dem eigenen Server des Betreibers, verschlüsselt mit der Windows-Datenschutz-API (DPAPI). Dazu kommen ein Upload-Protokoll (IDs, Titel, Zeitpunkte der eigenen Videos) und Gesamt-Aufrufzahlen des eigenen Kanals. Keine Cookies, kein Tracking.

4. Weitergabe

Es werden keine Daten verkauft oder an Dritte weitergegeben und keine Daten für Werbung genutzt. Die Nutzung von Daten aus Google-APIs hält sich an die Google API Services User Data Policy einschließlich der Limited-Use-Anforderungen.

5. Zugriff widerrufen

Jederzeit unter security.google.com/settings/security/permissions. Danach funktioniert das gespeicherte Token nicht mehr und wird beim nächsten Lauf automatisch gelöscht.

6. Löschung

Nach einem Widerruf oder auf Anfrage werden alle gespeicherten API-Daten innerhalb von 7 Tagen gelöscht. Gespeicherte API-Daten werden mindestens alle 30 Tage aktualisiert oder gelöscht, ausgenommen IDs und Titel der eigenen Uploads im Upload-Protokoll.

7. Kontakt

Fragen oder Löschanfragen bitte über den YouTube-Kanal NopeMyth (@nopemyth).
