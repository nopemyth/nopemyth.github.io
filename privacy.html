Privacy Policy

App: “Shorts Kanal Uploader” · Operator: NopeMyth (YouTube channel @nopemyth) · Last updated: 9 November 2026

1. Who uses this app

“Shorts Kanal Uploader” is a private internal tool used only by the operator of the YouTube channel NopeMyth (@nopemyth). It is not offered to the public, and no other person signs in to it.

2. Use of YouTube API Services

This app uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service (youtube.com/t/terms). Information is also handled according to the Google Privacy Policy (policies.google.com/privacy).

Through the YouTube Data API v3 the app only:

  • uploads the operator's own videos to the operator's own channel (as private videos, with a scheduled publishing time), sets their thumbnails and adds them to the channel's own playlists,
  • maintains the operator's own channel branding (description, keywords, banner),
  • reads data of the operator's own channel and videos (titles, upload status, view and subscriber counts),
  • reads the comments under the operator's own videos and replies to them as the channel (at most 20 replies per day; scope youtube.force-ssl).

Through the YouTube Analytics API (scope yt-analytics.readonly) the app reads reports of the operator's own channel only (for example views, average view duration and average view percentage of our own videos) to monitor quality.

The app does not access private data of other users or channels. It never edits or deletes other users' comments, and it does not read contacts. It does not access any other person's mailbox.

Through the Gmail API (scope gmail.readonly; optionally gmail.compose, used only to create drafts) the app reads the operator's own mailbox of the channel account only: sender, subject, date, authentication result and Google's short preview of new messages, to notify the operator about important messages (for example from YouTube, Google, Buffer or TikTok). It does not read message bodies or attachments, never sends, deletes or modifies messages, and never opens links contained in messages.

3. What is stored, and where

  • OAuth token: stored only on the operator's own server, encrypted with Windows Data Protection (DPAPI). Never shown, logged or shared.
  • Upload log: IDs, titles and upload times of our own videos.
  • Statistics: view counts and analytics figures of our own channel, used internally to track progress and quality.
  • Comments: comment texts are not stored. Only comment IDs, the action taken and our own reply are logged.
  • Email: message contents are not stored. Only message IDs are kept (to avoid duplicate notifications); a short notice (sender, subject, preview without links) is pushed to the operator's own phone.

This website uses no cookies and no tracking.

4. Sharing

No data is sold, shared with or transferred to third parties. No data is used for advertising.

5. Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Gmail data is never used for advertising, never shared, and never used to train AI models.

6. Revoking access

Access can be revoked at any time via the Google security settings page at security.google.com/settings/security/permissions (also reachable at myaccount.google.com/permissions). After revocation the app can no longer access YouTube; the stored token stops working and the app deletes it automatically on its next run.

7. Data deletion

  • On revocation: the stored token is deleted automatically, and all other stored API data (upload log, statistics) is deleted within 7 days.
  • On request: deletion of stored API data can be requested via the contact below; it is completed within 7 days.
  • Regularly: statistics are only kept as long as needed for internal tracking; stored API data is refreshed or deleted at least every 30 days, except the IDs and titles of our own uploads in the upload log.

8. Contact

Questions or deletion requests: via the YouTube channel NopeMyth (@nopemyth).

Datenschutzerklärung

App: „Shorts Kanal Uploader“ · Betreiber: NopeMyth (YouTube-Kanal @nopemyth) · Stand: 9. November 2026

1. Wer die App nutzt

„Shorts Kanal Uploader“ ist ein privates internes Werkzeug, das ausschließlich der Betreiber des YouTube-Kanals NopeMyth (@nopemyth) nutzt. Die App wird nicht öffentlich angeboten; niemand sonst meldet sich darin an.

2. Nutzung der YouTube-API-Dienste

Diese App nutzt die YouTube-API-Dienste. Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

Über die YouTube Data API v3 macht die App nur Folgendes: eigene Videos auf den eigenen Kanal hochladen (privat, mit geplantem Veröffentlichungszeitpunkt), Thumbnails setzen und Videos eigenen Playlists hinzufügen, das Branding des eigenen Kanals pflegen sowie Daten des eigenen Kanals und der eigenen Videos lesen (Titel, Status, Aufrufe, Abonnenten). Außerdem liest sie die Kommentare unter den eigenen Videos und beantwortet sie als Kanal (höchstens 20 Antworten pro Tag; Bereich youtube.force-ssl).

Über die YouTube Analytics API (Bereich yt-analytics.readonly) liest die App nur Berichte des eigenen Kanals (z. B. Aufrufe, durchschnittliche Wiedergabedauer und -anteil der eigenen Videos), um die Qualität zu prüfen. Private Daten anderer Nutzer oder Kanäle werden nicht abgerufen; fremde Kommentare werden nie bearbeitet oder gelöscht.

Über die Gmail API (Bereich gmail.readonly; optional gmail.compose, nur zum Anlegen von Entwürfen) liest die App ausschließlich das eigene Postfach des Kanal-Kontos: Absender, Betreff, Datum, Authentifizierungsergebnis und Googles Kurzvorschau neuer Mails, um den Betreiber über wichtige Mails (z. B. von YouTube, Google, Buffer, TikTok) zu informieren. Mail-Texte und Anhänge werden nicht gelesen; es wird nie gesendet, gelöscht oder verändert, und Links in Mails werden nie geöffnet.

3. Was gespeichert wird

Das OAuth-Token liegt nur auf dem eigenen Server des Betreibers, verschlüsselt mit der Windows-Datenschutz-API (DPAPI). Dazu kommen ein Upload-Protokoll (IDs, Titel, Zeitpunkte der eigenen Videos) sowie Aufruf- und Analytics-Zahlen des eigenen Kanals. Kommentartexte werden nicht gespeichert, nur Kommentar-IDs, die Aktion und unsere eigene Antwort. Mail-Inhalte werden nicht gespeichert, nur Mail-IDs (gegen Doppelmeldungen); eine kurze Meldung (Absender, Betreff, Vorschau ohne Links) geht an das eigene Handy des Betreibers. Gmail-Daten werden nie für Werbung, Weitergabe oder KI-Training genutzt. Die Website nutzt keine Cookies und kein Tracking.

4. Weitergabe

Es werden keine Daten verkauft oder an Dritte weitergegeben und keine Daten für Werbung genutzt. Die Nutzung von Daten aus Google-APIs hält sich an die Google API Services User Data Policy einschließlich der Limited-Use-Anforderungen.

5. Zugriff widerrufen

Jederzeit unter security.google.com/settings/security/permissions. Danach funktioniert das gespeicherte Token nicht mehr und wird beim nächsten Lauf automatisch gelöscht.

6. Löschung

Nach einem Widerruf oder auf Anfrage werden alle gespeicherten API-Daten innerhalb von 7 Tagen gelöscht. Gespeicherte API-Daten werden mindestens alle 30 Tage aktualisiert oder gelöscht, ausgenommen IDs und Titel der eigenen Uploads im Upload-Protokoll.

7. Kontakt

Fragen oder Löschanfragen bitte über den YouTube-Kanal NopeMyth (@nopemyth).
